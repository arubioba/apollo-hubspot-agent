# ARA Knowledge Base

This folder contains Markdown extracts of Freelan's ARA source documents. These files are intended to become the versioned knowledge base used by ARA agents for ICP reasoning, account intelligence, and engagement preparation.

## Sources

- `ara-framework.md`: ARA framework and operating model.
- `ara-service-portfolio.md`: ARA / Freelan service portfolio.
- `market-category.md`: Market category definition.
- `category-narrative.md`: Category narrative and positioning.
- `freelan-ara-profile.md`: distilled agent-ready profile for ARA reasoning and prep notes.

## Usage Guidance

Use this knowledge base to ground:

- Freelan value proposition.
- ICP and disqualification criteria.
- Opportunity detection.
- Account intelligence summaries.
- ARA Prep Meeting notes in HubSpot.

Do not treat this folder as raw prompt text only. Use `freelan-ara-profile.md` as the agent-ready profile, and use the source extracts for deeper grounding and future audit evidence.
